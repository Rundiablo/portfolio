DC Motor Position & Velocity Control

This project explores the modeling and feedback control of a DC motor for both position and velocity regulation. Controllers were designed and tested to make the motor follow desired position and speed commands while evaluating system response, stability, and control performance. The project connects control-system theory with the behavior of a physical electromechanical system through simulation and experimental testing.

Project Overview

DC motors are widely used in robotic and mechatronic systems where accurate control of motion is required. This project focused on developing a feedback control system capable of controlling both the rotational velocity and angular position of a DC motor. The goal was to make the motor accurately track a desired speed or position rather than simply applying a voltage and allowing the motor to operate without feedback. The project was developed to apply control-system concepts to a physical electromechanical system and investigate the differences between simulated and real-world behavior. A mathematical model of the motor was used to study its response and design controllers in simulation before implementing and testing the control system on the physical motor. The main engineering problem was achieving stable and accurate motor motion despite the dynamics and limitations of the physical system. By measuring the motor's actual motion and comparing it with the desired reference, feedback control could be used to continuously correct the motor's behavior and reduce tracking error. This provided a practical way to study how modeling, controller design, simulation, and hardware implementation work together in a real control system.

02

Design Objectives

The main objectives of the project were:

  • Develop a simple mathematical model that represents the dynamic behavior of the DC motor.
  • Design feedback controllers to regulate the rotational velocity and angular position of the motor
  • Simulate the control systems and evaluate their stability, tracking accuracy, and transient response.
  • Implement the controllers on the physical motor and compare the experimental response with the simulated response.

03

System Design

The system uses encoder feedback to measure the motion of the DC motor and provide feedback to the controller. The same hardware platform was used for both velocity and position control, with the measured output compared against the desired reference to determine the required motor command.

Open-Loop Experimental Response

The motor was tested in open loop by varying the PWM command and measuring the resulting steady-state angular velocity. The measured response shows an approximately linear increase in motor speed as the PWM command increases over the tested range.

Velocity Control Design

Velocity Feedback Architecture

The velocity control system uses a closed-loop feedback architecture to regulate the rotational speed of the DC motor. The desired angular velocity, ωref(t), is compared with the measured angular velocity, ωf(t), to determine the velocity error:

eω(t) = ωref(t) - ωf(t)

The velocity error is supplied to the PID controller, which calculates the motor control input using proportional, integral, and derivative actions:

u(t) = Kpeω(t) + Ki∫0t eω(τ)dτ + Kd deω(t) dt

The resulting control signal is applied to the motor, while the measured motor velocity is continuously fed back to the controller. This allows the controller to adjust the motor input based on the difference between the commanded and measured velocity.

Encoder-Based Velocity Measurement

The motor's angular velocity was determined from the encoder position measurements. The encoder count was first converted into angular position using the encoder resolution of 980 counts per revolution:

θ(t) = N(t) 2π 980

where N(t) represents the cumulative encoder count and θ(t) is the angular position of the motor shaft in radians.

The change in angular position between two consecutive measurements was then calculated as:

Δθ = θk - θk-1

The elapsed time between the two measurements was also recorded. The angular velocity of the motor was then estimated by dividing the change in angular position by the elapsed time:

ω = Δθ Δt

This produced the motor velocity in radians per second. The calculated angular velocity was then used as the feedback measurement in the closed-loop velocity controller.

Experimental Tuning

The PID gains were tuned experimentally by adjusting the controller parameters and observing the resulting motor velocity response. Different gain combinations were tested while monitoring the response of the motor to the desired velocity command.

The responses were evaluated qualitatively based on stability, oscillation, overshoot, response speed, and the ability of the motor velocity to converge toward the desired value. The controller gains were adjusted until the system produced stable and acceptable velocity tracking.

Formal transient-response measurements such as rise time, settling time, and maximum overshoot were not calculated during the original experiment. Quantitative performance analysis is therefore identified as an area for improvement in a future iteration of the project.

Experimental Velocity Response

The final controller gains selected for the velocity-control experiment were Kp = 70, Ki = 25, and Kd = 0. Although the controller was implemented using a PID structure, the derivative term was disabled in the final tuning, resulting in PI control.

The response shows a rapid increase in motor velocity followed by oscillations during the initial transient. As the response progresses, the motor velocity approaches approximately 8 rad/s and remains near this value with relatively small fluctuations. This tuning was selected because it provided stable velocity tracking with an acceptable experimental response.

Position Control Design

Position Feedback Architecture

The position-control system uses closed-loop feedback to control the angular position of the motor shaft. The desired angular position, θref(t), is compared with the measured motor position, θf(t), to determine the position error:

eθ(t) = θref(t) - θf(t)

The controller uses the position error to determine the motor command. As the motor moves toward the desired angular position, encoder feedback continuously updates the measured position and reduces the error between the commanded and actual positions.

Encoder-Based Position Measurement

The angular position of the motor shaft was determined directly from the cumulative encoder count. With an encoder resolution of 980 counts per revolution, each encoder count represents a known fraction of one complete rotation.

θ(t) = N(t) 2π 980

where N(t) is the cumulative encoder count and θ(t) is the calculated angular position in radians. This position measurement was used as the feedback signal for the closed-loop position controller.

Experimental Tuning

The position controller was tuned experimentally by adjusting the controller parameters and observing the motor's response to commanded angular positions.

The response was evaluated qualitatively based on stability, oscillation, overshoot, response speed, and the motor's ability to converge toward and remain near the desired angular position. Controller parameters were adjusted until acceptable position tracking was achieved.

Experimental Position Response

The final position-control gains used for the experiment were Kp = 85, Ki = 4, and Kd = 5. The controller was tested using a commanded angular position of 360°, corresponding to approximately 6.28 rad.

The experimental response shows that the motor rapidly approached the desired angular position with little visible overshoot. After reaching the reference position, the measured position remained close to the commanded value without noticeable sustained oscillation. This tuning provided stable position tracking and allowed the motor to move to and maintain the desired angular position.

Testing & Results

Experimental testing was performed in three stages: open-loop motor characterization, closed-loop velocity control, and closed-loop position control.

Open-loop testing showed how the motor's steady-state angular velocity changed with PWM command, providing an initial understanding of the motor's physical response.

For velocity control, encoder feedback was used to estimate motor angular velocity and regulate the motor toward the desired speed. The final velocity controller used Kp = 70, Ki = 25, and Kd = 0, resulting in stable tracking near the commanded velocity.

For position control, encoder position feedback was used to move the motor toward and maintain a desired angular position. The final controller used Kp = 85, Ki = 4, and Kd = 5. The motor successfully approached and maintained the 360° reference position with little visible overshoot.

Challenges & Engineering Decisions

One of the main challenges in the project was converting encoder measurements into useful feedback variables. The encoder count was used directly to determine angular position, while angular velocity had to be estimated from the change in position over a measured time interval.

Controller tuning was performed experimentally by testing different combinations of proportional, integral, and derivative gains and observing the resulting motor response. Numerical position and velocity measurements were collected during the experiments and used to generate the response plots. Controller performance was evaluated primarily by visually comparing these plots and observing stability, oscillation, overshoot, and convergence toward the desired reference. The underlying time-series data were not retained after the experiments, so quantitative transient-response metrics such as rise time, settling time, and percent overshoot were not calculated.

Another limitation of the original experiment was that complete time-domain open-loop response data were not saved. Although the steady-state relationship between PWM command and motor velocity was characterized, the available data were not sufficient to reliably identify a dynamic transfer-function model of the physical motor.

Future Improvements

A future iteration of the project will focus on experimental system identification and quantitative controller evaluation. Rather than relying primarily on qualitative observation, the complete time-domain response of the motor will be recorded and analyzed.

Experimental System Identification

A known step input will be applied to the motor while recording the resulting angular velocity as a function of time. The measured data will then be used to identify an experimental dynamic model of the motor.

Step Input → ω(t) Data → System Identification → G(s) → Model Validation

Quantitative Performance Analysis

Closed-loop response data will also be recorded so that controller performance can be evaluated using standard transient-response specifications such as rise time, settling time, maximum overshoot, and steady-state error.

Model-Based Controller Design

Once an experimentally validated motor model is available, controller gains can be designed using the identified system dynamics rather than relying primarily on trial-and-error tuning. The predicted response of the model can then be compared directly with the experimental motor response.

What I Learned

This project provided practical experience implementing feedback control on a physical electromechanical system. I gained experience converting encoder measurements into position and velocity feedback, implementing closed-loop motor control, and experimentally tuning controller gains.

The project also demonstrated the difference between applying control theory in simulation and working with a physical system, where sensor measurements, sampling, actuator limitations, and experimental data collection become important parts of the control problem.

One of the main lessons from the project was the importance of recording complete experimental data. This motivated the next stage of the project, which will focus on system identification, model validation, and quantitative evaluation of controller performance.
